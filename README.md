# git-practice

Git의 기본 명령어와 GitHub 원격 저장소 사용법을 연습하는 저장소입니다.

## 학습 목표

- 작업 디렉터리, 스테이징 영역, 커밋의 차이 이해하기
- 파일을 추가하고 의미 있는 단위로 커밋하기
- `.gitignore`로 공개하지 않을 파일 제외하기
- 로컬 커밋을 GitHub에 push하기

## 문서 구성

| 파일 | 내용 |
| --- | --- |
| `README.md` | 저장소 소개와 학습 목표 |
| `.gitignore` | 개인정보와 불필요한 파일의 제외 규칙 |
| `git-basics.md` | Git의 기본 개념 |
| `commands.md` | 자주 사용하는 명령어 |
| `practice.md` | 파일 수정부터 push까지의 실습 순서 |

## 공개 정보 관리

이 저장소는 공개 가능한 학습 문서만 포함합니다. 강의 자료 원본, 녹취,
개인정보, 인증 정보는 포함하지 않습니다. 커밋 작성자는 학습용 별칭과
실제 메일을 수신하지 않는 `example.invalid` 주소를 사용합니다.

문서 중심의 실습이므로 별도 설치나 빌드가 필요하지 않습니다.
